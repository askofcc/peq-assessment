# PEQ 效能测试 3.0 (PEQ Effectiveness Quotient 3.0)

> 基于史蒂芬·柯维（Stephen R. Covey）经典著作《高效能人士的七个习惯》（*The 7 Habits of Highly Effective People*）体系构建的 72 题深度效能测评系统。

---

## 🌟 核心特性 (Features)

### 1. 深度测评与理论重构
- **72 道专业自陈诊断题**：覆盖七大习惯维度（H1~H7），采用 6 级李克特量表（非常不同意 → 非常同意）。
- **科学反向计分模型**：正向题与反向思维题分离计算，杜绝答题惯性偏差，得分归一化为 0~100 标准分。
- **成长的三阶段进化模型（Maturity Continuum）**：
  - **阶段一 · 个人成功（Private Victory）**：习惯 1–3（积极主动、以终为始、要事第一），赢得自我掌控与内核独立。
  - **阶段二 · 公众成功（Public Victory）**：习惯 4–6（双赢思维、知彼解己、统合综效），赢得信任共创与深度互赖。
  - **阶段三 · 不断更新（Continuous Renewal）**：习惯 7（不断更新），身心智灵四维平衡，维持产出与产能平衡（P/PC）。
- **柯维成熟度定论深度诊断**：
  - “没有个人独立，就没有健康的互赖”。当公众成功得分显著高于个人成功时，系统自动触发根基预警，提示防止陷入“以迎合讨好掩盖自控不足”的假性互赖。
- **6 大核心效能角色原型画像（Archetype Persona）**：
  - 战略领航者（Strategic Catalyst）
  - 单打独斗型先锋（Lone Pioneer）
  - 和合奉献者（Harmonious Pleaser）
  - 蓝图构想家（Visionary Dreamer）
  - 高压冲刺者（Burnt-Out Sprinter）
  - 求索开拓者（Evolving Explorer）
- **分层动态落地建议（Actionable Blueprint）**：针对每个习惯的实际得分，给出专属的现状诊断、认知转变（Paradigm Shift）、可立即开始的 3 步微习惯（Micro-habits）以及避坑雷区。

### 2. 前端交互与体验打磨
- **自适应高精度 SVG 雷达图**：彻底修复移动端触控错位问题，支持悬停与标签点击，可与下方维度解析卡无缝联动。
- **72 题快捷答题卡（Question Matrix）**：右上角抽屉面板，直观展现 72 题完成进度（已答、未答、当前题），支持一键跨题跳转。
- **桌面端键盘快捷键**：
  - `1` ~ `6` 键：直接选择对应量表选项，平滑自动进入下一题；
  - `←` / `→`（或 `PageUp` / `PageDown`）：上一题 / 下一题；
  - `Enter`：在最后一题快速提交。
- **答题进度与历史自动归档**：
  - 作答中途刷新或意外退出，首页自动提示恢复（如已完成 28/72 题）；
  - 测试完成后自动归档于 `localStorage`，随时可重温报告。
- **交付与分享工具箱**：
  - **一键复制结构化报告**：一键生成格式优美的 Markdown/纯文本报告摘要，方便粘贴至微信、飞书、Notion、邮件分享；
  - **打印 / 导出 PDF**：内置 `@media print` 打印专用样式，A4 纸排版优雅整洁，自动隐藏多余按钮并展开所有折叠项。
- **零外部依赖秒开**：无第三方外部字体 CDN 阻塞，内嵌跨平台高品质系统字体栈，国内与弱网环境 100ms 内瞬间呈现。

### 3. 多语言与智能语言匹配 (i18n)
- **智能自动匹配**：根据用户的浏览器/操作系统语言（`navigator.language`）自动切换为中文或英文。
- **右上角无缝切换**：点击 `🌐 English / 中文` 随时切换，当前作答进度与测评结果 100% 保持，无需刷新。
- **双语覆盖全景**：包括 72 题地道中英对照、7 大习惯理论、3 阶段解析、角色画像、计分说明与明细表。


## 🌐 发布与中国大陆用户访问优化 (Deployment & China CDN)

### 为什么选择 Vercel 而非 Cloudflare？
1. **网络路由差异**：
   - **Cloudflare 免费版**：中国大陆访问时流量几乎全部路由至美西（圣何塞/洛杉矶）Anycast 节点，物理往返延迟（RTT）通常高达 **220ms~350ms**，晚高峰国际出口拥堵时丢包率显著上升。
   - **Vercel Anycast 网络**：在亚太地区拥有香港（`hkg1`）和日本（`hnd1`）优质边缘节点。绑定自定义域名后，大陆电信、联通、移动用户通常会被路由至香港或日本节点，延迟通常仅为 **40ms~90ms**，首屏加载极为顺畅。
2. **极简自包含优势**：
   - 本项目已剔除所有外部不稳定第三方 CDN，单个 HTML 资源开启 Gzip/Brotli 压缩后仅 **~20KB**，在 Vercel 边缘缓存下可实现毫秒级瞬间打开。

### 国内部署关键提醒（必读）：
- Vercel 默认分配的免费二级域名 `*.vercel.app` 在中国大陆多数地区存在 DNS 污染和 SNI 阻断。
- **建议方案**：在 Vercel 项目设置中，绑定一个您自己的**自定义域名**（如 `peq.yourdomain.com`，CNAME 指向 `cname.vercel-dns.com` 或 A 记录指向 `76.76.21.21`）。自定义域名在国内解析通常完全通畅！
